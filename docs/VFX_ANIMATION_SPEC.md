# VAYLORN 혈술 애니메이션 규칙

## 핵심 원칙

- 완성 이미지 한 장의 확대를 주 연출로 사용하지 않는다.
- 모든 주요 혈술은 `예고 → 발동 → 최대 타격 → 붕괴`의 서로 다른 실루엣 4장을 사용한다.
- 프레임 전환은 순방향으로만 진행하며 최대 타격 프레임을 의도적으로 유지한다.
- 돌진 계열은 이미지 내부 변화뿐 아니라 효과 중심도 시전자에서 목표까지 이동한다.
- 마지막 프레임은 단순 축소가 아니라 파편, 잔상, 끊어진 에너지 형태로 소멸한다.

## 런타임 타이밍

- 0~10%: 예고 프레임 유지
- 10~24%: 예고에서 발동으로 빠르게 전환
- 24~40%: 발동에서 최대 타격으로 전환
- 40~64%: 최대 타격 프레임 유지
- 64~82%: 붕괴 프레임으로 전환
- 82~100%: 붕괴 프레임 유지와 알파 소멸

타이밍의 단일 기준은 `VfxAnimationRules`이며 JVM 테스트가 프레임의 역행과 최대 타격 유지 여부를 검증한다.

## 아틀라스 구성

- `vfx_blood_arts_anim_a_v2.png`: 혈창, 흡혈 사슬, 혈폭발, 쇄도
- `vfx_blood_arts_anim_b_v2.png`: 검우, 혈뢰 사슬, 진홍 기둥, 월식
- 각 파일은 4열×4행이며 열은 시간 순서, 행은 스킬 종류다.
- 새 아틀라스 디코딩이 실패할 때에만 기존 정적 혈술 아틀라스를 안전 폴백으로 사용한다.
