# 전투 중 스토리 전달 규격

## 해결하려는 문제

지역 진입 스토리와 다음 지역 스토리 사이에 4개의 장기 사냥 웨이브와 1개의 보스 웨이브가 있다. 기존 버전은 이 구간에서 전투 목표만 표시해 카엘, 리안, 녹스의 갈등이 장시간 사라졌다.

## 적용 규칙

- 3개 지역 × 5개 웨이브마다 시작 대사와 중반 대사를 하나씩 제공한다.
- 대사는 전투를 일시정지하거나 입력을 막지 않는 오버레이로 재생한다.
- 웨이브 배너가 사라진 뒤 시작 대사를 표시한다.
- 중간 대사는 해당 웨이브 목표의 절반을 처치했을 때 예약한다.
- 보스 등장 배너가 재생되는 동안 대사 타이머를 멈추고, 배너 종료 후 이어서 보여준다.
- `피의 기억`, 스킬명, 보스 배너는 같은 화면 구역을 공유하며 `보스 > 기억 > 스킬` 순으로 표시한다.
- 반복 회차의 첫 웨이브는 기존 도입을 반복하지 않고 등장인물이 되감긴 밤을 인식한다.

## 화면 안전 규격

- 봉인 추적 로드맵은 HUD 보조 버튼 아래 10px 여백을 둔다.
- 피의 기억 패널은 로드맵 아래 14px 여백을 둔다.
- 스킬명 컷인은 기존 HUD 버튼 위가 아니라 피의 기억과 같은 전투 오버레이 구역을 사용한다.
- 좌측 HIT 카운터와 14px 이상 떨어지도록 대사 패널은 x=204부터 시작한다.

데이터 완전성, 반복 회차 분기와 패널 간 최소 여백은 JVM 회귀 테스트로 고정한다.
