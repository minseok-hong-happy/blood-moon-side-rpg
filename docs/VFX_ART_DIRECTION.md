# 혈월 스킬 VFX 아트 방향

## 참고 원칙

메이플스토리의 공식 업데이트와 스킬 자료를 참고해 다음 시각 원칙만 추출했다.

- 스킬마다 멀리서도 구분되는 고유 실루엣
- 흰색 중심핵, 선명한 주색, 어두운 외곽 연기의 3단 명암
- 완전한 원보다 찢어지고 흐르는 비대칭 외곽
- 한 장면 안에서 준비, 팽창, 타격, 소멸이 읽히는 크기 변화
- 캐릭터와 몬스터를 완전히 가리지 않는 투명 여백

원본 게임의 이미지, 로고, 캐릭터, 문양은 복사하지 않았다. 최종 리소스는 혈월의 붉은 고딕 세계관을 위해 새로 생성한 독립적인 손그림 이미지다.

## 제작 리소스

- 파일: `app/src/main/res/drawable-nodpi/vfx_blood_arts_atlas_v1.png`
- 제작 방식: OpenAI 내장 이미지 생성으로 균일한 크로마 배경 위에 생성한 뒤 로컬 소프트 매트·디스필 처리
- 구성: 4열 × 2행, 총 8셀
- 순서: 혈창, 흡혈, 혈월 폭발, 혈영쇄도, 적월검우, 혈사슬, 진홍기둥, 개기월식
- 사용 방식: 스킬별 셀을 잘라 위치, 방향, 팽창률, 투명도를 시간에 따라 보간

## 렌더링 정책

- 이미지 VFX가 주효과이며 기존 원·선·광륜 렌더러는 이미지 디코딩 실패 시에만 사용한다.
- 혈창 투사체도 손그림 이미지 셀을 사용한다.
- 기존 파티클은 이미지 위에 얹는 타격 파편과 속도 보조 효과로만 남긴다.
- 아틀라스는 전투 시작 시 지연 로드하고 화면 종료 시 명시적으로 해제한다.
