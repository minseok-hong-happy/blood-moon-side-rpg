# AI 오디오 생성 기록

v4.1.0-demo의 모든 음악과 효과음은 외부 음원·샘플·멜로디를 사용하지 않고 AI가 설계한 합성 규칙으로 프로젝트 내부에서 생성했습니다.

## 배경음

- 파일: `app/src/main/res/raw/bgm_blood_road.wav`
- 길이: 41.74초 루프
- 구성: 92 BPM, D minor 중심, 저음 혈월 펄스, 4화음 패드, 8분음표 아르페지오, 저음 타격과 종소리형 선율
- 목적: 자동 사냥을 방해하지 않는 어두운 전진감과 지역 공통 테마

## 효과음

- 가벼운 타격과 강타
- 대시
- 혈창, 흡혈, 혈월 폭발
- 플레이어 피격
- 레벨업과 UI 입력

타격음은 `SoundPool`의 재생속도를 매번 조금씩 바꿔 자동 3연격이 같은 샘플의 반복처럼 들리지 않게 했습니다. BGM은 `MediaPlayer`로 반복 재생합니다.

## 재생성

```powershell
python .\tools\generate_audio_assets.py
```

생성기는 고정 난수 시드를 사용하므로 같은 소스에서 같은 WAV 자산을 다시 만들 수 있습니다.
