# 오리지널 오디오 생성 기록

모든 음악과 효과음은 외부 음원·샘플·멜로디를 사용하지 않고 AI가 설계한 합성 규칙으로 프로젝트 내부에서 생성했습니다.

## 배경음

- 파일: `app/src/main/assets/audio/bgm_blood_road.wav`
- 길이: 약 46.15초 루프
- 구성: 104 BPM, D minor 중심, 고딕 패드, 16분음표 혈현 아르페지오, 킥·스네어·하이햇, 저음 혈월 펄스와 절제된 애니메이션풍 리드
- 목적: 자동 사냥의 속도감을 살리면서 전투 효과음의 주파수 영역을 가리지 않는 지역 공통 테마
- 재생: Godot `AudioStreamPlayer`, -9.5 dB, 종료 신호 반복 및 1초 간격 재생 감시

## 효과음

- 가벼운 타격과 강타
- 대시
- 혈창, 흡혈, 혈월 폭발
- 플레이어 피격
- 레벨업과 UI 입력

타격음은 Godot 오디오 풀의 재생속도를 매번 조금씩 바꿔 자동 3연격이 같은 샘플의 반복처럼 들리지 않게 했습니다.

## 재생성

```powershell
python .\tools\generate_audio_assets.py
```

BGM만 다시 만들 때는 `--bgm-only`를 사용합니다.

생성기는 고정 난수 시드를 사용하므로 같은 소스에서 같은 WAV 자산을 다시 만들 수 있습니다.
