# 혈월: 밤의 계승자

스스로 전진하고 싸우는 뱀파이어 카엘에게 혈술과 성장으로 개입하는 세로형 방치 횡스크롤 RPG 콘셉트 데모입니다. Android Studio나 외부 게임 엔진 없이 Android Canvas와 Java로 제작되며, 인터넷 연결 없이 플레이할 수 있습니다.

## 게임 구성

- 월하 성역, 잿빛 숲, 진홍 성채로 이어지는 3개 지역
- 지역마다 일반 몬스터 웨이브 4개와 보스 웨이브 1개
- 동시에 최대 3마리가 등장하는 연속 사냥 전투
- 경험치, 레벨, 골드, 누적 처치 수와 반복 회차 난이도
- 앱을 꺼도 최대 8시간 누적되는 지역·성장 단계 기반 골드와 경험치
- 복귀 시간, 획득 보상, 상승 레벨을 한눈에 보여주는 오프라인 사냥 보고서
- 생명, 완력, 혈기, 회복의 영구 능력 강화
- 혈창, 흡혈, 혈월 폭발의 해금 및 숙련 강화
- 무기, 갑옷, 혈석 전리품을 보관하는 6칸 아이템 가방
- 장착 장비 비교, 상위 장비 교체, 하위 장비 골드 분해
- 오른쪽으로 자동 전진하고 거리에 맞춰 이어지는 자동 3연격
- 새 적은 오른쪽에서 진입하되 실제 교전은 화면 중앙에 유지하는 전투 재중앙화
- 혈창, 흡혈, 혈월 폭발과 개입용 무제한 대시
- 카엘, 리안, 솔바르의 관계와 혈월의 비밀을 보여주는 지역별 스토리
- 발 접지와 진행 방향을 통일한 2D 셀 애니메이션
- 16자세 연속 동작 아틀라스, 프레임 보간과 고정 스텝 위치 보간
- 준비·발동·회복이 이어지는 공격/대시/혈술 모션 상태
- 80~130ms 기본 공격 판정과 적중 후 혈술 캔슬 입력 버퍼
- 달리면서 이어지는 자동 3연격과 화면 흔들림을 줄인 속도선·잔상 연출
- 직접 개입하는 혈창·흡혈·혈월 폭발의 고유 벡터 스킬 아이콘
- 레벨 3·6·9·12·15에 해금되는 혈영쇄도·적월검우·혈사슬·진홍기둥·개기월식
- 혈뢰, 검우, 피의 기둥, 월식 광륜과 다중 충격파를 겹친 전용 스킬 이펙트
- 동시 최대 6마리의 밀집 웨이브와 보스 호위 몬스터
- 밝아진 배경·전투 지면과 캐릭터 판독용 광원
- AI가 작곡·합성한 오리지널 다크 판타지 BGM과 저지연 전투 효과음
- 히트스톱, 방향성 카메라 킥, 피격 반동, 충격 플래시가 결합된 타격 피드백
- 혈창의 다중 잔상, 흡혈의 곡선 혈류, 혈월 폭발의 충격파·광선·화면 펄스
- 장애물과 점프 없이 전투, 성장, 이야기 확인에 집중한 세로 화면

전체 이야기와 이번 데모의 검증 목표는 [`CONCEPT_DEMO.md`](CONCEPT_DEMO.md)에 정리되어 있습니다.
자동사냥 RPG 비교 조사와 이번 적용 판단은 [`docs/MARKET_RESEARCH-2026-idle-rpg.md`](docs/MARKET_RESEARCH-2026-idle-rpg.md)에 기록했습니다.

## 저장과 업데이트 안전성

- 체크섬이 있는 이중 저장 슬롯을 번갈아 사용해 중단된 쓰기에서 이전 체크포인트를 보호합니다.
- v1 탐험 또는 v2 결투 저장을 자동 변환하며, v3 성장 저장도 가방이 추가된 v4 형식으로 안전하게 이어집니다.
- 새 모험은 기존 진행도를 지우기 전에 별도 확인 화면을 거칩니다.
- Android `INTERNET` 권한을 요청하지 않으며 광고, 분석 SDK, 계정 로그인 기능이 없습니다.
- 기존 설치본과 같은 패키지 ID 및 서명 인증서를 사용해 덮어쓰기 업데이트가 가능합니다.

## 빌드

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
.\tools\build_release.ps1
```

스크립트는 영문 임시 경로에서 단위 테스트, 린트, R8 릴리스 빌드, APK 서명 및 인증서 검증을 수행한 뒤 `dist` 폴더와 바탕 화면에 버전이 포함된 APK를 복사합니다. Java 17과 프로젝트에 설정된 Android SDK가 필요합니다.

오디오 원본은 외부 샘플 없이 `tools/generate_audio_assets.py`가 결정론적으로 생성합니다.

최소 Android 6.0(API 23), 세로 화면 전용입니다.
