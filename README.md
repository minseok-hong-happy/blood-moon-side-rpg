# VAYLORN

> **프로젝트 페이지:** [최신 APK 다운로드·패치노트·QA·기획 문서 보기](https://minseok-hong-happy.github.io/blood-moon-side-rpg/)

스스로 전진하고 싸우는 뱀파이어 카엘에게 혈술과 성장으로 개입하는 세로형 방치 횡스크롤 RPG 콘셉트 데모입니다. Godot 4.7.1의 2D 애니메이션·파티클·오디오를 기존 Android 앱에 임베드했으며, 인터넷 연결 없이 플레이할 수 있습니다.

## 게임 구성

- 잿빛 성역, 망각의 숲, 진홍 성채로 이어지는 3개 지역
- 지역마다 일반 몬스터 웨이브 4개와 보스 웨이브 1개
- 동시에 최대 24마리가 화면을 채우고, 처치 즉시 빈자리를 메우는 장기 연속 사냥 전투
- 경험치, 레벨, 골드, 누적 처치 수와 반복 회차 난이도
- 앱을 꺼도 최대 8시간 누적되는 지역·성장 단계 기반 골드와 경험치
- 복귀 시간, 획득 보상, 상승 레벨을 한눈에 보여주는 오프라인 사냥 보고서
- 생명, 완력, 혈기, 회복의 영구 능력 강화
- 혈창, 흡혈, 혈월 폭발의 해금 및 숙련 강화
- 무기, 갑옷, 혈석 전리품을 보관하는 6칸 아이템 가방
- 획득 즉시 부위별 상위 장비를 판별하는 자동 장착
- 오른쪽으로 자동 전진하고 거리에 맞춰 이어지는 자동 3연격
- 새 적은 오른쪽에서 진입하되 실제 교전은 화면 중앙에 유지하는 전투 재중앙화
- 혈창, 흡혈, 혈월 폭발과 개입용 무제한 대시
- 카엘, 리안, 솔바르의 관계와 혈월의 비밀을 보여주는 지역별 스토리
- 15개 웨이브 각각의 시작·중반에 재생되는 30개 비차단형 `피의 기억` 대사
- 네 번의 사냥과 지역 보스까지 현재 위치를 보여주는 봉인 추적 로드맵
- 반복 회차를 세계관의 되감긴 밤으로 인식하는 전용 대사
- 발 접지와 진행 방향을 통일한 2D 셀 애니메이션
- 16자세 동작 아틀라스, 상태 잠금, 트윈 이동을 결합한 연속 모션
- 준비·발동·회복이 이어지는 공격/대시/혈술 모션 상태
- 370~480ms 간격의 3연격과 짧은 히트스톱으로 구성한 빠른 공격 응답
- 달리면서 이어지는 자동 3연격과 화면 흔들림을 줄인 속도선·잔상 연출
- 직접 개입할 수 있고 작은 화면에서도 선명한 밉맵·안전 여백을 적용한 신규 8종 손그림 혈술 아이콘
- 무기·갑옷·유물 손그림 아이콘과 희귀도 테두리를 갖춘 착용 장비·6칸 가방 UI
- 화면에 진입한 적을 즉시 포착하고 준비 표시와 같은 판정으로 발동하는 자동 혈술
- 레벨 3·6·9·12·15에 해금되는 혈영쇄도·적월검우·혈사슬·진홍기둥·개기월식
- 혈뢰, 검우, 피의 기둥, 월식 광륜과 다중 충격파를 겹친 전용 스킬 이펙트
- 중력·회전·감속으로 흩어지는 손그림 혈정 파편과 화면 잘림을 막는 대형 혈술 안전영역
- AI로 제작한 8종 손그림 혈술 아틀라스와 이미지 기반 스킬 애니메이션
- AI로 제작한 12셀 타격 애니메이션과 일반타격·강타·처치별 접촉 프레임
- 피격 백색 실루엣, 피해 숫자 위계, 연속 HIT 카운터를 결합한 타격 판독
- 자동 혈술명 컷인과 지역 보스 전용 등장 배너
- APK 빌드 전에 이미지 리맵과 모바일 텍스처 포함 여부를 검사하는 VFX 배포 게이트
- 동시 최대 24마리, 초기 16마리 즉시 배치와 빈자리 즉시 증원, 32~60마리 규모의 밀집 웨이브
- 720px 전투 화면을 4등분한 첫 구간(x=180)에 주인공을 고정하고, 적 전투선을 왼쪽으로 재배치
- 일반 웨이브 중반에 출현하는 정예 몬스터와 희귀 이상 장비 보상
- 3.2초 안에 처치를 이어가며 5연속마다 추가 골드를 얻는 사냥 연쇄
- 태양의 심판관, 망각의 문지기, 월식의 군주로 실루엣부터 구분되는 지역별 고유 보스전
- 호위 몬스터를 포함해 18~26마리가 등장하고 체력 55%부터 패턴이 강화되는 2단계 보스전
- 주인공보다 약 1.9배 크게 보이는 12자세 보스 아틀라스와 전용 이름표·체력바·회전 오라·공격 예고
- 밝아진 배경·전투 지면과 캐릭터 판독용 광원
- 104 BPM 전투 리듬으로 재작곡하고 중단 시 자동 복구하는 오리지널 고딕 BGM과 저지연 전투 효과음
- Noto Sans KR 가변 굵기, 확대된 모바일 글자, 외곽선과 단순화한 스킬 카드 정보 구조
- 짧은 히트스톱, 4.8px 이하의 제한된 화면 흔들림, 충격 플래시가 결합된 타격 피드백
- 혈창의 다중 잔상, 흡혈의 곡선 혈류, 혈월 폭발의 충격파·광선·화면 펄스
- 장애물과 점프 없이 전투, 성장, 이야기 확인에 집중한 세로 화면

## 저장과 업데이트 안전성

- 체크섬이 있는 이중 저장 슬롯을 번갈아 사용해 중단된 쓰기에서 이전 체크포인트를 보호합니다.
- v1 탐험 또는 v2 결투 저장을 자동 변환하며, v3 성장 저장도 가방이 추가된 v4 형식으로 안전하게 이어집니다.
- Android `INTERNET` 권한을 요청하지 않으며 광고, 분석 SDK, 계정 로그인 기능이 없습니다.
- 기존 설치본과 같은 패키지 ID 및 서명 인증서를 사용해 덮어쓰기 업데이트가 가능합니다.

## 빌드

Windows PowerShell에서 다음 명령을 실행합니다.

```powershell
.\tools\build_release.ps1
```

스크립트는 영문 스테이징 경로에서 Godot 리소스 임포트, 게임 규칙 테스트, 900프레임 자동전투 시뮬레이션, `project.binary` 생성, JVM 단위 테스트, 린트, APK 내부 리소스 검사, 서명·인증서 검증을 수행합니다. 이어서 ARM 배포본과 Godot 에셋이 바이트 단위로 같은 x86_64 QA APK를 API 24/OpenGL ES 3 에뮬레이터에 제한시간이 있는 비스트리밍 방식으로 설치하고, 실제 게임 장면 준비와 초기 전투 생존까지 확인합니다. 모든 게이트를 통과한 ARM APK만 `dist`에 생성됩니다. Godot 4.7.1, Java 17, 프로젝트에 설정된 Android SDK가 필요합니다.

오디오 원본은 외부 샘플 없이 `tools/generate_audio_assets.py`가 결정론적으로 생성합니다.

최소 Android 7.0(API 24), 세로 화면 전용입니다.
